プライバシーポリシー

制定日：2026年10月19日　最終更新日：2026年10月20日

このプライバシーポリシー（以下「本ポリシー」）は、アニメ視聴記録（以下「本アプリ」）が、利用者の情報をどのように扱うかを説明するものです。

要点

  • 記録とプロフィール（名前・写真）は、利用者の端末の中にだけ保存します。本アプリの運営者（以下「運営者」）はサーバーを持っておらず、これらを受け取ることも見ることもありません。
  • アカウントの登録・ログインはありません。利用状況の分析（アクセス解析）、広告、利用者の追跡はしていません。
  • 画面を表示するために、アプリの配信元・文字の形（フォント）・作品の画像のサーバーと通信します。このとき、通常のウェブの通信と同じく、IP アドレスなどが相手に届きます（第3条）。

第1条（端末に保存する情報）

本アプリは、次の情報を利用者の端末のブラウザの保存領域に保存します。端末の外には送りません。

  1. 記録：作品名、視聴の状態、見た話数・全話数、星の評価、感想・メモ、放送時期、登録・更新した日時
  2. プロフィール：名前、写真。写真は、利用者が選んだ1枚だけを小さく切り抜いて保存します。写真ライブラリのほかの写真を読み取ることはありません。
  3. 設定：並び順、絞り込み、表示している画面、案内を閉じた日、バックアップを最後に書き出した日
  4. 本アプリのファイル（画面・作品データ）の一時保存：電波の届かない所でも開けるようにするためです。

第2条（集めない情報）

本アプリは、次の情報を集めません。

  • 氏名・メールアドレス・電話番号などの連絡先（利用者がお問い合わせで書いたものを除く）
  • 位置情報、連絡先、カメラ・マイクの情報
  • 広告 ID、利用状況の分析のための情報
  • 他社のアプリやウェブサイトをまたいで利用者を追跡するための情報（クッキーなど）

第3条（画面の表示のための通信）

本アプリは、画面を表示するために、利用者の端末から次のサーバーに接続します。このとき、通常のウェブの通信と同じく、利用者の端末の IP アドレス、ブラウザと OS の種類、読み込むファイルのアドレス、日時などが相手に届き、それぞれの相手の方針に従って扱われます。記録・感想・メモ・プロフィールは送りません。

1. GitHub, Inc.（GitHub Pages）

目的：本アプリの画面と作品データの配信

方針：GitHub のプライバシーに関する声明

2. Google LLC（Google Fonts）

目的：文字の形（フォント）の読み込み

方針：Google のプライバシーポリシー、Google Fonts のプライバシーについて

3. TVmaze

目的：作品のポスター画像の読み込み

上の情報に加えて、どのポスター（作品）を読み込んだかと、本アプリのアドレス（https://qooh28.github.io/）が届きます。

方針：TVmaze Privacy Policy

4. 各作品の公式サイト

目的：TVmaze にポスターがない作品の画像の読み込み

上の情報に加えて、どの画像（作品）を読み込んだかが届きます。本アプリのアドレスは送らない設定にしています。

方針：各公式サイトの方針に従います。

画像を読み込むサーバーには、利用者がどの作品の画像を表示したかが分かることがあります。

第4条（利用者が自分で開くリンク・送る情報）

  1. 本アプリの中の Annict・TVmaze・各作品の公式サイト・GitHub などへのリンクは、利用者が押したときだけ開きます。開いた先では、その先の方針が適用されます。
  2. 画像の削除のご依頼やお問い合わせを GitHub から送ると、その内容と GitHub のアカウント名は公開されます。
  3. 「バックアップを書き出す」を使うと、記録とプロフィール（写真を含む）が入ったファイルが作られ、利用者が選んだ場所（「ファイル」アプリや共有先など）に保存・送信されます。共有先での扱いは、その共有先の方針に従います。

第5条（情報の確認・削除）

  1. 記録とプロフィールは、本アプリの中でいつでも確認・修正できます。作品は編集画面の「削除」で、写真はプロフィールの「写真を外す」で消せます。
  2. すべて消すときは、ブラウザの設定で、このサイト（qooh28.github.io）のウェブサイトデータを削除してください。ホーム画面に追加して使っている場合は、ホーム画面から本アプリを削除してください。手順は端末やブラウザによって異なります。
  3. 運営者は利用者の記録を持っていないため、運営者が代わりに確認・削除することはできません。

第6条（本ポリシーの変更）

運営者は、本ポリシーを変更することがあります。広告や利用状況の分析など、扱う情報が変わる機能を入れるときは、その前に本ポリシーを改め、本アプリ内でお知らせします。変更したときは、このページの日付を更新します。

第7条（お問い合わせ）

本ポリシーについてのお問い合わせは、こちらのお問い合わせページからご連絡ください（GitHub のアカウントが必要です。お問い合わせの内容は公開されます）。

本アプリの利用の条件は、利用規約をご覧ください。
