# アニメ視聴記録

見たいアニメ、視聴中の話数、見終わった作品の評価と感想を記録する Web アプリです。
iPhone のホーム画面に追加すると、アプリのように使えます（PWA）。

## できること

- 作品の登録：タイトル、全話数、感想・メモ（放送時期は「作品をさがす」や入力候補から選ぶと自動で入り、表示だけされる）
- 状態の管理：見たい／視聴中／見終わった／中断
- 「＋1話」ボタンで見た話数を記録（全話数に届くと「見終わった」に変わる。直後なら元に戻せる）
- 星5段階の評価
- 状態での絞り込み、タイトルや感想での検索（ひらがな・カタカナの違いは区別しない）
- 並び替え：更新が新しい順／放送時期が新しい順／評価順（星の数）／タイトル順
  - タイトル順は読みのあいうえお順。英語の題名も日本語の読み（ONE PIECE → わんぴーす）で並び、括弧や記号は読まない
  - 読みは作品一覧から取る。作品一覧にない題名を手で入力した場合、かなで始まればその読みで並び、漢字や英字で始まるものは最後にまとめる
- 一覧のカードから ＋1話／−1話
- 「作品をさがす」：Annict に載っているアニメ作品を、作品名で探して登録できる（人気順／評価順（自分がつけた星の数）／放送時期が新しい順／タイトル順）
- 作品名を入力すると候補が出て、話数・放送時期が自動で入る
- テレビアニメは TVmaze のポスター、TVmaze にない作品（劇場版など）は各作品の公式サイトの画像を出典つきで表示。どちらもない・読み込めないときは、題名の1文字を出した色付きの四角（下の「ポスター画像について」）
- 利用規約（`terms.html`。メニューの「利用規約」から開く）
- アカウント：名前と、写真ライブラリから選んだ写真のアイコン（写真は端末の中で 256px の正方形に切り抜いて保存し、どこにも送らない）
- ランク：見た話数（記録した全作品の「見た話数」の合計）で11段階（ノーマル → ルーキー 100話 → アマチュア 300話 → ベテラン 500話 → ブロンズ 1,000話 → シルバー 2,000話 → ゴールド 3,000話 → プラチナ 4,000話 → ダイアモンド 5,000話 → ミスリル → オリハルコン）。ミスリルとオリハルコンは作品数（「見終わった」作品だけ）の条件もあり、画面では達成条件を伏せる。名前もそのランクになるまで「？？？」にする。定義は `app.js` の `RANKS`。アカウント画面の ⓘ で一覧と達成条件を見られる。記録の数字（見終わった作品・視聴中の作品・見たい作品・中断した作品・見た話数・平均の星）も出す
- バックアップの書き出しと読み込み（JSON ファイル。プロフィールも入る）
- オフラインでも開ける

記録とプロフィールは、その端末のブラウザの中（localStorage）に保存されます。ログインは要りません（サーバーとログインは今後の段階で入れる予定）。
機種変更やブラウザのデータ削除の前には、右上の「…」からバックアップを書き出してください。

## 作品データ（catalog.json）の作り方

「作品をさがす」の一覧は、[Annict](https://annict.com) の API から作った `catalog.json` を読み込みます。

```sh
pip install pykakasi alkana   # 読み（タイトル順用）を作るのに使う

# catalog.json を作る（Annict の全作品。タイトル検索用で、配信サービスの情報は入れない）
python3 scripts/build_catalog.py

# Annict に問い合わせず、今の catalog.json の読みだけ作り直す
python3 scripts/build_catalog.py --update-readings
```

- どの作品にも、タイトル順に使う読み（ひらがな）を付けます（`scripts/readings.py`）。
  Annict の読みがなは記号を取って整え、読みがながない作品（全体の約3分の1）は題名から作ります。
  同じシリーズの作品の読みがなを先に使い、残りは漢字を pykakasi、英単語を alkana で読みます。
  自動で作った読みは、固有名詞などで間違うことがあります（例：「空の境界」→ そらのきょうかい）。

- Annict のアクセストークンが必要です（annict.com の設定 → アプリ → 個人用アクセストークン、読み込み専用）。
  環境変数 `ANNICT_TOKEN` で渡すか、Claude Code の環境の Network secrets に `api.annict.com` 宛てで保存します。
- 新しい作品が増えるので、ときどき作り直してください。

### ポスター画像について（covers.json）

テレビアニメのポスターは [TVmaze](https://www.tvmaze.com) の画像を、TVmaze の画像置き場（static.tvmaze.com）から読み込んで表示します。
TVmaze の API は CC BY-SA 4.0 で、商用でも使えます（条件は、アプリから TVmaze へのリンクで出典を示すことと、ShareAlike）。
アプリは「作品をさがす」の下と、右上の「…」に出典のリンクを出しています。

```sh
# covers.json を作る（Annict・Wikidata・TVmaze に問い合わせる。TVmaze は10秒に20回までなので、1時間ほどかかる）
# --cache を付けると、取ったデータを残して、止まっても続きから取れる
python3 scripts/build_covers.py --cache .cache/covers
```

- 結びつけ方は3段階です。間違ったポスターを出さないよう、1つに決まるものだけを使います。劇場版には付けません（TVmaze はテレビ番組だけ）。
  1. Annict の作品の MyAnimeList の番号を、[Wikidata](https://www.wikidata.org)（CC0）で TVmaze の番組に結びつける。
  2. 結びつかない人気のテレビ・Web 作品（上位3,000作品の中）は、題名で TVmaze を検索し、同じ時期に始まった日本語のアニメを探す。
     題名がぴったり合う番組を先に決め、残りは候補が1つに絞れるときだけ使う。
  3. 2期・3期などは、Annict で同じシリーズの作品が結びついた番組から、同じ時期に始まった季を探す。
     その季にすでに別の作品が結びついていれば（同じ時期のミニアニメなど）使わない。
- `covers.json` は TVmaze のデータから作ったものなので CC BY-SA 4.0 です。Annict のデータ（`catalog.json`）とは分けて置いています。
- ポスターの著作権は、それぞれの作品の権利者にあります。アプリにも「作品画像の著作権は、各作品の権利者に帰属します。」と出しています。

#### 公式サイトの画像（official_images.json）

TVmaze のポスターがない作品は、Annict の作品データに記録された公式サイトの画像（og:image など）を出します。
アプリは画像を保存せず公式サイトから直接読み込み（リファラーは送らない）、作品の編集画面に「画像の出典：公式サイト」と権利者の表記を出します。
画像の著作権は各作品の権利者にあり、利用の許諾を受けたものではありません（あにふぉりお・AniHub などと同じ考え方）。

```sh
# covers.json を作ったあとに実行する（https で、実際に画像として読めたものだけを使う）
python3 scripts/build_official_images.py --cache .cache/covers
```

- サイト共通の画像（多くの作品が同じ画像の URL を持つもの）は、作品の画像ではないので使いません。

#### 権利者から画像の削除を頼まれたら

アプリの「…」→「画像の削除を依頼する」から、GitHub の課題（Issues）に依頼が届きます。
作品を確かめたら、Annict の作品 ID を指定してポスターを外し、公開し直します。

```sh
python3 scripts/build_covers.py --remove 10079 --note "issue #3 で依頼"   # covers.json と official_images.json から外し、covers_blocklist.txt に記録
```

`scripts/covers_blocklist.txt` に書いた作品は、covers.json・official_images.json を作り直しても付きません。
- 以前は [AniList](https://anilist.co) の画像を使っていましたが、2026-10-18 にやめました。
  AniList の API の利用規約（https://docs.anilist.co/guide/terms-of-use ）が、アニメの記録アプリ（"anime and manga list or tracker services"）での利用と、データの大量取得を禁じているためです。

## App Store に出す前に

- ストアのスクリーンショットに、実在の作品の画像を写さない（Apple は権利のない作品の画像が写ったスクリーンショットを認めていない）。
  URL の最後に `?screenshot` を付けて開くと（例：https://qooh28.github.io/test/?screenshot ）、架空の作品だけを並べ、ポスターを出さない表示になります。
  この表示では記録・設定・プロフィールを一切保存しないので、自分の記録はそのまま残ります。
- 画像の出典（TVmaze・公式サイト）と「作品画像の著作権は、各作品の権利者に帰属します。」をアプリに出しておく（出してある）。
- 利用規約（`terms.html`）を用意しておく（ある）。課金・広告を始める前に、専門家に一度見てもらうと安心。
- 権利者からの削除依頼を受ける窓口を用意しておく（「…」→「画像の削除を依頼する」）。

### 配信サービスの情報について

`--services` を付けると、Annict の配信の記録（U-NEXT、Netflix など）がある作品だけを、サービス付きで書き出します。
ただし Annict の配信の記録は新作に偏っていて主要作品でも抜けが多いため、今は使っていません。
作品データにサービスの情報がなければ、アプリはサービスの絞り込みや表示を出しません。
TMDB から入れる案もありましたが、使わないことにしました（2026-10-15）。

## 公開のしかた（GitHub Pages）

公開中の URL：https://qooh28.github.io/test/

`gh-pages` ブランチの中身が公開されます（`gh-pages` ブランチを作ると、GitHub が自動で Pages を有効にした）。
`master` を更新したら、公開にも反映するために `gh-pages` にも送ります。

```sh
git push origin master
git push origin master:gh-pages   # 1〜2分で公開中のサイトに反映される
```

- 無料プランでは、リポジトリが公開（public）のときだけ GitHub Pages を使えます。非公開に戻すと、サイトは止まります。
- 画面で設定する場合は、**Settings → Pages** の **Branch** で公開するブランチを選びます。

## iPhone のホーム画面に追加する

1. Safari で公開した URL を開く
2. 共有ボタン →「ホーム画面に追加」

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の構成 |
| `style.css` | 見た目（黒を基調にした、音楽配信アプリ風のデザイン） |
| `app.js` | 動き（記録の保存、絞り込み、編集など） |
| `sw.js` | オフライン用のキャッシュ。ファイルを更新したら `CACHE` の番号を上げる |
| `manifest.webmanifest` | ホーム画面に追加したときの名前やアイコン |
| `icons/` | アプリのアイコン |
| `catalog.json` | アニメ作品の一覧（`scripts/build_catalog.py` で作る） |
| `scripts/build_catalog.py` | Annict から `catalog.json` を作るスクリプト |
| `scripts/readings.py` | タイトル順に使う読み（ひらがな）を作る |
| `covers.json` | 作品ごとの TVmaze のポスター（`scripts/build_covers.py` で作る。CC BY-SA 4.0） |
| `scripts/build_covers.py` | Annict・Wikidata・TVmaze から `covers.json` を作るスクリプト |
| `scripts/covers_blocklist.txt` | 権利者から削除を頼まれ、画像を付けない作品 |
| `official_images.json` | TVmaze にない作品の、公式サイトの画像の URL・権利者の表記（`scripts/build_official_images.py` で作る） |
| `scripts/build_official_images.py` | Annict から `official_images.json` を作るスクリプト |
| `terms.html` | 利用規約 |

ビルドは不要です。ファイルをそのまま置けば動きます。
