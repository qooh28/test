# アニメ視聴記録

見たいアニメ、視聴中の話数、見終わった作品の評価と感想を記録する Web アプリです。
iPhone のホーム画面に追加すると、アプリのように使えます（PWA）。

## できること

- 作品の登録：タイトル、全話数、感想・メモ（放送時期は「作品をさがす」や入力候補から選ぶと自動で入り、表示だけされる）
- 状態の管理：見たい／視聴中／見終わった／中断
- 「＋1話」ボタンで見た話数を記録（全話数に届くと「見終わった」に変わる。直後なら元に戻せる）
- 星5段階の評価
- 状態での絞り込み、タイトルや感想での検索（ひらがな・カタカナの違いは区別しない）
- 並び替え：更新が新しい順／放送時期が新しい順／評価順（星の数）／タイトル順
  - タイトル順は読みのあいうえお順。英語の題名も日本語の読み（ONE PIECE → わんぴーす）で並び、括弧や記号は読まない
  - 読みは作品一覧から取る。作品一覧にない題名を手で入力した場合、かなで始まればその読みで並び、漢字や英字で始まるものは最後にまとめる
- 一覧のカードから ＋1話／−1話
- 「作品をさがす」：Annict に載っているアニメ作品を、作品名で探して登録できる（人気順／評価順（自分がつけた星の数）／放送時期が新しい順／タイトル順）
- 作品名を入力すると候補が出て、話数・放送時期が自動で入る
- 作品のジャケット画像を表示（AniList の画像。見つからない作品や読み込めないときは、題名の1文字を出した色付きの四角）
- アカウント：名前と、写真ライブラリから選んだ写真のアイコン（写真は端末の中で 256px の正方形に切り抜いて保存し、どこにも送らない）
- ランク：見た話数（記録した全作品の「見た話数」の合計）で11段階（ノーマル → ルーキー 100話 → アマチュア 300話 → ベテラン 500話 → ブロンズ 1,000話 → シルバー 2,000話 → ゴールド 3,000話 → プラチナ 4,000話 → ダイアモンド 5,000話 → ミスリル → オリハルコン）。ミスリルとオリハルコンは作品数（「見終わった」作品だけ）の条件もあり、画面では達成条件を伏せる。名前もそのランクになるまで「？？？」にする。定義は `app.js` の `RANKS`。アカウント画面の ⓘ で一覧と達成条件を見られる。記録の数字（見終わった・視聴中・見たい・中断・見た話数・平均の星）も出す
- バックアップの書き出しと読み込み（JSON ファイル。プロフィールも入る）
- オフラインでも開ける

記録とプロフィールは、その端末のブラウザの中（localStorage）に保存されます。ログインは要りません（サーバーとログインは今後の段階で入れる予定）。
機種変更やブラウザのデータ削除の前には、右上の「…」からバックアップを書き出してください。

## 作品データ（catalog.json）の作り方

「作品をさがす」の一覧は、[Annict](https://annict.com) の API から作った `catalog.json` を読み込みます。

```sh
pip install pykakasi alkana   # 読み（タイトル順用）を作るのに使う

# catalog.json を作る（Annict の全作品。タイトル検索用で、配信サービスの情報は入れない）
python3 scripts/build_catalog.py

# Annict に問い合わせず、今の catalog.json の読みだけ作り直す
python3 scripts/build_catalog.py --update-readings
```

- どの作品にも、タイトル順に使う読み（ひらがな）を付けます（`scripts/readings.py`）。
  Annict の読みがなは記号を取って整え、読みがながない作品（全体の約3分の1）は題名から作ります。
  同じシリーズの作品の読みがなを先に使い、残りは漢字を pykakasi、英単語を alkana で読みます。
  自動で作った読みは、固有名詞などで間違うことがあります（例：「空の境界」→ そらのきょうかい）。

- ジャケット画像は、Annict の作品に入っている MyAnimeList の番号で [AniList](https://anilist.co) の作品を探し、その画像を使います。
  `catalog.json` には画像のファイル名だけを入れ、アプリは画面に出た作品の画像だけを AniList の画像置き場（s4.anilist.co）から読み込みます。
  作り直しには `graphql.anilist.co` への接続が必要です（AniList は1分に30回までなので、画像の対応づけに10分ほどかかります）。
- Annict のアクセストークンが必要です（annict.com の設定 → アプリ → 個人用アクセストークン、読み込み専用）。
  環境変数 `ANNICT_TOKEN` で渡すか、Claude Code の環境の Network secrets に `api.annict.com` 宛てで保存します。
- 新しい作品が増えるので、ときどき作り直してください。

### 配信サービスの情報について

`--services` を付けると、Annict の配信の記録（U-NEXT、Netflix など）がある作品だけを、サービス付きで書き出します。
ただし Annict の配信の記録は新作に偏っていて主要作品でも抜けが多いため、今は使っていません。
作品データにサービスの情報がなければ、アプリはサービスの絞り込みや表示を出しません。
今後は TMDB（配信情報は JustWatch 提供）から入れる予定です。

## 公開のしかた（GitHub Pages）

公開中の URL：https://qooh28.github.io/test/

`gh-pages` ブランチの中身が公開されます（`gh-pages` ブランチを作ると、GitHub が自動で Pages を有効にした）。
`master` を更新したら、公開にも反映するために `gh-pages` にも送ります。

```sh
git push origin master
git push origin master:gh-pages   # 1〜2分で公開中のサイトに反映される
```

- 無料プランでは、リポジトリが公開（public）のときだけ GitHub Pages を使えます。非公開に戻すと、サイトは止まります。
- 画面で設定する場合は、**Settings → Pages** の **Branch** で公開するブランチを選びます。

## iPhone のホーム画面に追加する

1. Safari で公開した URL を開く
2. 共有ボタン →「ホーム画面に追加」

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の構成 |
| `style.css` | 見た目（黒を基調にした、音楽配信アプリ風のデザイン） |
| `app.js` | 動き（記録の保存、絞り込み、編集など） |
| `sw.js` | オフライン用のキャッシュ。ファイルを更新したら `CACHE` の番号を上げる |
| `manifest.webmanifest` | ホーム画面に追加したときの名前やアイコン |
| `icons/` | アプリのアイコン |
| `catalog.json` | アニメ作品の一覧（`scripts/build_catalog.py` で作る） |
| `scripts/build_catalog.py` | Annict から `catalog.json` を作るスクリプト |
| `scripts/readings.py` | タイトル順に使う読み（ひらがな）を作る |

ビルドは不要です。ファイルをそのまま置けば動きます。
