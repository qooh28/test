# アニメ視聴記録

見たいアニメ、視聴中の話数、見終わった作品の評価と感想を記録する Web アプリです。
iPhone のホーム画面に追加すると、アプリのように使えます（PWA）。

## できること

- 作品の登録：タイトル、全話数、感想・メモ（放送時期は「作品をさがす」や入力候補から選ぶと自動で入り、表示だけされる）
- 状態の管理：見たい／視聴中／見終わった／中断
- 「＋1話」ボタンで見た話数を記録（全話数に届くと「見終わった」に変わる。直後なら元に戻せる）
- 星5段階の評価
- 状態での絞り込み、タイトルや感想での検索（ひらがな・カタカナの違いは区別しない）
- 並び替え：更新が新しい順／放送時期が新しい順／評価順（星の数）／タイトル順
- 一覧のカードから ＋1話／−1話
- 「作品をさがす」：Annict に載っているアニメ作品を、作品名で探して登録できる（人気順／評価順（自分がつけた星の数）／放送時期が新しい順／タイトル順）
- 作品名を入力すると候補が出て、話数・放送時期が自動で入る
- バックアップの書き出しと読み込み（JSON ファイル）
- オフラインでも開ける

記録はその端末のブラウザの中（localStorage）に保存されます。ログインは要りません。
機種変更やブラウザのデータ削除の前には、右上の「…」からバックアップを書き出してください。

## 作品データ（catalog.json）の作り方

「作品をさがす」の一覧は、[Annict](https://annict.com) の API から作った `catalog.json` を読み込みます。

```sh
# catalog.json を作る（Annict の全作品。タイトル検索用で、配信サービスの情報は入れない）
python3 scripts/build_catalog.py
```

- Annict のアクセストークンが必要です（annict.com の設定 → アプリ → 個人用アクセストークン、読み込み専用）。
  環境変数 `ANNICT_TOKEN` で渡すか、Claude Code の環境の Network secrets に `api.annict.com` 宛てで保存します。
- 新しい作品が増えるので、ときどき作り直してください。

### 配信サービスの情報について

`--services` を付けると、Annict の配信の記録（U-NEXT、Netflix など）がある作品だけを、サービス付きで書き出します。
ただし Annict の配信の記録は新作に偏っていて主要作品でも抜けが多いため、今は使っていません。
作品データにサービスの情報がなければ、アプリはサービスの絞り込みや表示を出しません。
今後は TMDB（配信情報は JustWatch 提供）から入れる予定です。

## 公開のしかた（GitHub Pages）

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にする
3. **Branch** で `master` と `/ (root)` を選び、Save を押す
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

非公開（private）のリポジトリで GitHub Pages を使うには、GitHub の有料プランが必要です。
無料プランの場合は、リポジトリを公開（public）にしてから設定してください。

## iPhone のホーム画面に追加する

1. Safari で公開した URL を開く
2. 共有ボタン →「ホーム画面に追加」

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の構成 |
| `style.css` | 見た目（ライト／ダークの両方） |
| `app.js` | 動き（記録の保存、絞り込み、編集など） |
| `sw.js` | オフライン用のキャッシュ。ファイルを更新したら `CACHE` の番号を上げる |
| `manifest.webmanifest` | ホーム画面に追加したときの名前やアイコン |
| `icons/` | アプリのアイコン |
| `catalog.json` | アニメ作品の一覧（`scripts/build_catalog.py` で作る） |
| `scripts/build_catalog.py` | Annict から `catalog.json` を作るスクリプト |

ビルドは不要です。ファイルをそのまま置けば動きます。
